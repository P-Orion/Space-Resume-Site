Projects

LLM Network Analyzer — Personal, 2025

Upload a packet capture, get a plain-English security briefing — Gemma 2 12B runs fully on-device via Ollama, so no packet ever leaves the machine. The hard part was getting a general-purpose local model to return consistent, six-category structured findings instead of free-form text; solved with constrained prompting and a streaming WebSocket pipeline, so results appear as they're generated, then export as a shareable report.

Python · FastAPI · Scapy · Angular · Ollama · Gemma 2

BrainBench — Senior Design, 2025–26

Comparing small local LLMs on math reasoning is easy to get wrong — naive benchmarks let mismatched problem difficulty or inconsistent prompting skew the results. Built a matched-subset statistical methodology to control for that, then ran Qwen3, Gemma 3, and Phi-3 head-to-head. Presented at the Northrop Grumman Engineering & Science Student Design Showcase and revised into IEEE conference format.

LLM Evaluation · Statistical Analysis · Ollama · IEEE Format
