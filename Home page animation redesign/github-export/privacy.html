Privacy & analytics

Updated October 5, 2026

I use Umami Cloud to understand how people find and use this portfolio, so I can improve the site.

What is measured

  • Visits and pageviews, approximate country/region/city, browser, operating system, screen size, and language.
  • Referring website domains and campaign labels, such as links shared on LinkedIn or NFC cards.
  • Which portfolio sections enter view and clicks on résumé, email, phone, LinkedIn, and project links.
  • Selections in the skills directory, program dossiers, and project archive, plus page-load performance and visit duration.

Click events record the type of action and portfolio section. Email addresses, phone numbers, and full outgoing link URLs are excluded from those events. Only supported campaign labels are retained from page query parameters; page anchors and other query parameters are removed.

Analytics uses no tracking cookies, custom personal identifiers, session recordings, or cross-site advertising tracking. Approximate location is derived from network information; the site does not request precise GPS location or ask visitors to identify themselves.

Browser privacy settings

This site respects Do Not Track and Global Privacy Control browser signals. Analytics does not run when JavaScript is disabled. You can contact me below with privacy questions or objections to analytics.

Service providers and retention

Umami Cloud processes analytics for this site. The current free plan retains analytics for six months. Read Umami’s privacy policy for its service practices.

The portfolio also loads fonts from Google Fonts and display libraries from unpkg. The site’s hosting and these providers receive the network requests needed to serve their files. Browser privacy signals control Umami measurement. This privacy page itself loads no analytics or third-party display resources.
